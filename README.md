# PRYM 60+ — Landing Page

Landing page premium do programa **PRYM 60+** da ProLife Centro de Saúde da Mente.

## Stack

- Next.js 15 · React 19 · TypeScript
- Tailwind CSS v4 · shadcn/ui · Motion · Lucide

## Desenvolvimento

```bash
npm install
node scripts/create-placeholders.mjs
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Imagens

Substitua os placeholders em `public/images/` mantendo os mesmos nomes de arquivo. Consulte `public/images/README.md`.
